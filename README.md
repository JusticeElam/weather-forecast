# Weather Forecast

A responsive weather forecast web application that displays real-time weather information using a weather API.

## 🚀 Features

- Search for weather information by city
- Display current weather conditions
- Show temperature and other weather details
- Real-time weather data from an external API
- Responsive design for different screen sizes
- User-friendly interface

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript (ES6+)
- Weather API
- REST API
- Responsive Web Design
